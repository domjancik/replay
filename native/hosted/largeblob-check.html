Can this passkey store a key?

This isolated test uses largeBlob, not PRF. It creates a passkey named rePlay largeBlob TEST. It never accesses your reMarkable connection or drawings and sends no test results to our server.

  1. Create the test passkey. Choose the provider you want to test (for example, Windows Hello).
  2. Write a random test encryption key alongside it.
  3. Read the key back and decrypt a synthetic test message.
  4. Reload this page, then read again. For a stronger check, close and reopen the browser and repeat.

Each step has its own button and may ask for your device PIN or biometrics. The test only saves a credential identifier and encrypted test message in this browser. The encryption key is not saved in browser storage.
