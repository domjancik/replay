Drawing replays for reMarkable notebooks.

rePlay turns the strokes in a notebook into a video of the drawing being built up. Choose a page, set the playback order and duration, then export the animation.

Open rePlay

Runs in your browser. No account with rePlay is needed.

How to use it

  1. Import a notebook

    Open a local .rmdoc file, pair with reMarkable Cloud, or connect your tablet over USB using the optional desktop companion.

  2. Choose a page and settings

    Select a page from the gallery. Set the duration, resolution and replay order. Use layer-by-layer order or entry order across layers.

  3. Create and download

    Create the replay and follow its progress in the queue. Download the video, or crop it and add a quick reverse to make a loop.

Files and connections

Notebook parsing and ink rendering run on your device. Imported notebooks and generated videos are stored in this browser’s local library.

Cloud pairing uses a stateless server relay. You can keep the connection for one session, save it encrypted with a password or a compatible passkey, or explicitly choose unprotected storage.

USB needs the desktop companion on Windows, macOS or Linux. Cloud and file imports work without it.

What to expect

rePlay renders ink, including textured pencil and brush strokes. It approximates the tablet’s appearance; it is not reMarkable’s native renderer.

Templates, typed text and PDF backgrounds are not included in ink replays. Some text-anchored pages need a matching native PDF. Large notebooks and high-resolution exports take more time and memory.

The project is open source. See the code and documentation or report a problem.
