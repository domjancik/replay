reMarkable cloud · local preview

Your pairing and notebook tree are encrypted in this browser. No companion CLI is needed. The relay forwards requests without saving credentials or the tree. While unlocked, it sees the credentials needed for cloud access.

Use a unique vault passphrase, not your reMarkable password. Page scripts can access credentials while unlocked; lock the vault on shared computers. The cloud token can authorize writes, although this app only reads documents.

Pair or unlock this browser

Get a one-time code from your reMarkable account, then pair this browser below.

At least 12 characters. The passphrase is never sent to the relay. Forgotten passphrases require pairing again. Closing this dialog locks the vault.

The code is sent through the relay to reMarkable and cleared from the field. Only the resulting pairing is saved, encrypted in this browser.

Disconnect this browser

Revoke removes this cloud registration and browser vault. Forget only removes this browser's saved pairing and tree. Imported notebooks and videos remain in the local replay library.

Downloaded ink feeds the same local replay engine. Templates and PDF backgrounds are omitted. Text-anchored pages may need a separately attached matching PDF. Live cloud-account validation is pending; this connector is experimental.
